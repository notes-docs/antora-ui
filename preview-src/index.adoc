:page-description: A Lucode-flavored Antora UI bundle inspired by the current Astro docs project.

Lucode Antora UI brings the look and feel of the current `lucode-starlight` docs site into an Antora-compatible bundle.
It focuses on clean typography, restrained navigation chrome, soft surfaces, and a balanced docs reading width.

== What This Theme Changes

This preview shows the first-pass theme shell that was ported from the Astro docs project:

* A sticky header with Lucode-style spacing and theme toggle
* A quieter left navigation rail with softer active states
* A centered reading column that matches the docs site rhythm
* A right-side table of contents with lighter hierarchy
* Light and dark theme tokens aligned with the current project

== Content Styling

The bundle also updates the default Antora content styling so prose feels closer to the current docs site.

.Inline elements
You can still mix `inline code`, https://example.org[links], and keyboard hints like kbd:[Ctrl,K] inside normal paragraphs.

[source,js]
----
document.documentElement.dataset.theme = 'dark'
window.localStorage.setItem('lucode-theme', 'dark')
----
